合作背景及权益

长线直播：小红书与游戏侧共创活动主题及方案；游戏方负责艺人邀约及直播执行细节，小红书侧配合开播、提供资源支持及部分游戏主播K的邀约；

主题demo：笑薯，原来你也玩鹅鸭杀

游戏薯的局

以游戏为主线串联，邀请影视综艺的好朋友一起组局——推开那扇门，就是一场破圈有趣的聚会

🎮 游戏 IP × 📕 小红书 × 🎬 影视综艺 = 一场破圈聚会
WHY · 为什么是「游戏薯的局」？
🎮
游戏 = 流量发动机
一次新游开测、版本上线或周年庆，本身就是一波现成的破圈热度。游戏是这场局的点火器——开局就带着话题和流量进场。
📕
小红书 = 种草放大器
平台不止给曝光，更要给用户种草。热度在这里会被搜索、被种草，变成真实的「我要追这部剧、玩这个游戏」。一次声量，长出无数篇自来水笔记。
🎬
剧/综 = 破圈引爆点
艺人的号召力 × 剧情/综艺话题度，让这场局从一次普通活动，变成一个有面孔、有名场面、能被全网讨论的事件。
THREE MATCH · 碰出三个 Match
✦ 世界观 MATCH
世界观相互映照
游戏 IP 与剧/综 IP 的世界观相互映照，能共同长出当期局型的 dresscode、主题餐饮、游戏环节。
👥 人群 MATCH
潜在人群互导
游戏玩家与剧/综观众互为潜在人群，都是年轻群体，一场局能让两边人群互相导流、互相种草。
✦ 声量 MATCH
声量叠加释放
游戏 IP 的破圈热度 × 艺人与剧综的话题度，在同一场局里叠加释放，声量大于各自单打。
FORMAT · 一场"被邀请的盲盒聚会"

录制形式，首发直播释出。每期局型根据当期游戏 IP 与剧/综方的世界观和话题来设定——Chill 局、整蛊局、Cosplay 局、复古局、暗黑局或共创局。件件都是破圈传播点，件件可被观众同款复刻。

👗 Dresscode
「角色 cosplay」「睡衣派对」「赛博朋克」——穿什么本身就是一个梗
🍹 主题特调创作
根据游戏 IP 与剧/综世界观设计主题餐饮，吃什么喝什么本身就是世界观的延伸
🎮 游戏任务解锁
聚会进程解锁游戏任务，全程当鼠鼠、保护 CP 等，天然的内容切片
